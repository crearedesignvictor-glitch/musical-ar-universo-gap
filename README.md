# Musical AR — Um sopro de vida | Universo GAP

Aplicação web em React + TypeScript + Vite para o projeto teatral e musical solidário **Musical AR — Um sopro de vida**, promovido pelo Universo GAP em Marabá, Pará.

## 🎭 Sobre o Projeto

O Musical AR reúne turmas da Educação Infantil e do Ensino Fundamental I em um espetáculo que combina música, movimento, imaginação e solidariedade.

- **Data principal:** 24 de Novembro de 2026
- **Local:** Teatro Municipal Eduardo Abdelnor, Marabá – PA
- **Sessões:** 17h e 19h30
- **Ação Solidária:** Entrada mediante a doação de materiais escolares novos para apoiar bibliotecas comunitárias e ações infantis.

## 🚀 Tecnologias

- **React 19** com TypeScript
- **Vite** para desenvolvimento e empacotamento rápido
- **CSS modular** com animações de cena, nuvens e pássaros em movimento
- **YouTube IFrame API** com controle integrado de áudio e silenciamento
- **Express.js** no backend de suporte (`server.js`)

## 🛠️ Comandos

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento (porta 3000)
npm run dev

# Checagem de tipos
npm run lint

# Compilar para produção
npm run build

# Iniciar servidor de produção
npm start
```
